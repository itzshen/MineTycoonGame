# Mine Tycoon

This is a part of final project of Programming Methodology I 2110215 course in Computer Engineering, Chulalongkorn University.

Mine Tycoon is a 2D automation and resource management game developed using JavaFX. The objective is to construct an efficient mining factory, manage resource processing lines, and maximize profits. The game operates on a grid-based placement mechanic where players strategically purchase and position various machines such as Droppers, Conveyor belts, Upgraders, and Furnaces to process raw materials into highly valuable items before depositing them into the Player Bank.

## How to Install and Play

1. Download `TycoonGame.jar`
2. Download `TycoonGame.bat` for Windows or `TycoonGame.sh` for Linux/macOS
3. Run the launcher for your OS:
   - Windows: double-click `TycoonGame.bat`
   - macOS/Linux: open a terminal in the folder and run `bash TycoonGame.sh` or `chmod +x TycoonGame.sh && ./TycoonGame.sh`

The game will launch with Java. Ensure Java Runtime Environment is installed.
